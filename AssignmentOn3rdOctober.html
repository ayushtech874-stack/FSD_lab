General Instructions

  • Use only HTML, CSS and Vanilla JavaScript.
  • Do not use React, Bootstrap, Tailwind CSS or other frameworks/libraries.
  • Use localStorage to persist data.
  • CRUD operations should happen without reloading the page.
  • Validate user input before adding or updating records.
  • Keep the code properly structured, readable and maintainable.
  • The final application should be responsive and user-friendly.

Question 1 — Student Management System

CRUD + Search + Filter + Statistics

Create a Student Management System using HTML, CSS and JavaScript. The application must implement complete CRUD operations for student records.

Student Fields

  • Student ID
  • Student Name
  • Email
  • Course
  • Marks

Required Functionality

1. CREATE — Add Student

  • Create a form containing all student fields.
  • All fields are required.
  • Student ID must be unique.
  • Email must be validated.
  • Marks must be between 0 and 100.
  • Clicking Add Student should add the record to the table.

2. READ — Display Students

The student table should contain:

  • ID
  • Name
  • Email
  • Course
  • Marks
  • Status
  • Actions
  • Status should show Pass if marks are 50 or above.
  • Status should show Fail if marks are below 50.
  • Each record must have Edit and Delete buttons.

3. UPDATE — Edit Student

  • Clicking Edit should populate the form with the selected student's data.
  • The Add Student button should change to Update Student.
  • After updating, the table and statistics should refresh automatically.

4. DELETE — Remove Student

  • Clicking Delete should ask for confirmation.
  • After confirmation, remove the student from the table and storage.

5. Search and Filter

  • Add a search box to search by student name or course.
  • Search results should update while typing.
  • Add filters: All / Passed / Failed.

6. Statistics

  • Total Students
  • Average Marks
  • Top Student

7. Data Persistence

  • Store student records in localStorage.
  • Records should remain available after refreshing or reopening the browser.

Expected Output

Your page should contain a student form, statistics section, search/filter controls and a student table.

Question 2 — Inventory Management System

CRUD + Search + Filter + Quantity Controls

Create an Inventory Management System using HTML, CSS and JavaScript. The application must implement complete CRUD operations for products.

Product Fields

  • Product ID
  • Product Name
  • Category
  • Price
  • Quantity

Required Functionality

1. CREATE — Add Product

  • Create a form containing all product fields.
  • All fields are required.
  • Product ID must be unique.
  • Price cannot be negative.
  • Quantity cannot be negative.
  • Clicking Add Product should add the product to the table.

2. READ — Display Products

The inventory table should contain:

  • Product ID
  • Product Name
  • Category
  • Price
  • Quantity
  • Status
  • Inventory Value
  • Actions
  • Inventory Value = Price × Quantity.
  • Quantity 0 → Out of Stock.
  • Quantity 1–4 → Low Stock.
  • Quantity 5 or more → Available.

3. UPDATE — Edit Product

  • Clicking Edit should populate the form with the selected product.
  • The Add Product button should change to Update Product.
  • Product ID should remain unique.
  • After updating, the table and statistics should refresh automatically.

4. DELETE — Remove Product

  • Clicking Delete should ask for confirmation.
  • After confirmation, remove the product from the table and storage.

5. Search and Category Filter

  • Add a search box to search by product name.
  • Search results should update while typing.
  • Add a category filter with: All Categories / Electronics / Clothing / Food / Other.

6. Quantity Controls

  • Provide + and − controls for product quantity.
  • Quantity must never become negative.
  • Status and inventory value must update automatically.
  • Statistics must also update automatically.

7. Statistics

  • Total Products
  • Total Inventory Value
  • Low Stock Products

8. Data Persistence

  • Store product records in localStorage.
  • Records should remain available after refreshing or reopening the browser.

Expected Output

Your page should contain a product form, statistics section, search/filter controls and an inventory table.
